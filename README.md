# STEP Java Assignments — Weeks 1–9

Solutions are organized by week. Weeks 1–7 contain a combined Java file with five solution methods/classes and sample demonstrations. Weeks 8–9 also contain separate input-driven `Problem1.java` through `Problem5.java` files.

## Contents
- Week 1: Arrays and strings
- Week 2: String operations and frequency counting
- Week 3: Classes, objects, constructors and static members
- Week 4: Array algorithms
- Week 5: Array references, helper methods, overloading and Comparable
- Week 6: Object-oriented programming and encapsulation
- Week 7: Encapsulation and access control
- Week 8: Billing, parking, electricity, bonuses and renewals
- Week 9: Abstract classes, interfaces and shared business rules

Compile the combined files from their folders. Week 8 and Week 9 standalone problems use package declarations; from the repository root, compile with `javac Week08/Problem1.java` and run with `java Week08.Problem1`.
