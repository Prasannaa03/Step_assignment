# STEP Java Assignments — Weeks 1–9

Solutions are organized by week. Each `WeekNN.java` file is self-contained and uses Java standard libraries only. Compile with `javac WeekNN.java` and run with `java WeekNN` from that week's directory.

## Contents
- Week 1: Arrays and strings
- Week 2: String operations and frequency counting
- Week 3: Classes, objects, constructors and static members
- Week 4: Array algorithms
- Week 5: Array references, helper methods, overloading and Comparable
- Week 6: Object-oriented programming and encapsulation
- Week 7: Encapsulation and access control
- Week 8: Polymorphic billing, parking, electricity, bonuses and renewals
- Week 9: Abstract classes, interfaces and shared business rules

These are worked solutions based on the assignment statements provided. Check your course's exact formatting requirements before submission.
